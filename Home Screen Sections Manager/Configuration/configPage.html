Existing Home Screen Sections

This area shows your current home screen sections. Sections made by/default by Jellyfin are labeled Jellyfin in blue, and sections made by this plugin are labeled in purple. You can change the two colors below. Sections made by this plugin are editable and sections made by Jellyfin are not. Click 'Create Section' to create a new section. Click 'Edit Section' to edit sections made by this plugin. Drag sections to rearrange them. Continue Watching is locked to being the top section media bar.

New Section Type Settings

Select which type of section you want to create. After this, you can select how you want the content to be organized.
