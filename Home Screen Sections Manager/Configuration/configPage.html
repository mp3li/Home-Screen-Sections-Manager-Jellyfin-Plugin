Automatic Home Screen Section Refresh Settings

Automatically refresh rule-based home screen sections when their collections, tags, or libraries gain newly added matching media.

Remove from Continue Watching and Next Up Settings

Add an X button when you hover over items in Continue Watching and Next Up. Click the X to remove that item from the row.

My List Settings

Add a per-user My List page and heart buttons for adding or removing media from My List.

Series Info Settings

Display season and episode totals on series and season pages. When runtime details are available, also show the estimated time playback will finish.

Infinite Scroll Settings

Select the libraries where Jellyfin should automatically load more media as you approach the bottom of the library page.

Collections on Detail Page Settings

Show an Also Part of These Collections section on supported media detail pages.

Enhanced Search Settings

Add grouped search modes for Movies and TV, Music, Books, and All Jellyfin media. This does not include Jellyseerr features.

Bread Crumbing Settings

Show a clickable location trail in the upper-left header on supported media detail pages.

This plugin uses the Abyss theme by AumGupta on GitHub. The Abyss theme includes CSS customization options. Those options have been added here, and some of those options have been changed by this plugin to allow further customization capabilities. Also, new customization options that are not originally part of the Abyss theme have also been added by this plugin.

Accent Color Settings

Choose the shared Abyss accent color used by hover states, including top navigation text, play and resume buttons, and sidebar menu items.

Top Navigation Color Settings

Customize the centered Home, Favorites, My List, and other page tabs.

Top Navigation Selected Text Color Settings

Customize the text color of the currently selected Home, Favorites, My List, or other top-navigation tab when it is not hovered. Hovering continues to use the Accent Color.

Play Button Color Settings

Customize Jellyfin play and resume buttons.

Watched Progress Color Settings

Customize watched-progress bars and playback progress bar colors.

Sidebar Icon Color Settings

Cuztomize the sidebar icons.

My List Heart Color Settings

Customize the heart buttons used to add media to My List.

Episode Count Pill Color Settings

Select the background color used for Abyss episode-count and indicator pills. Abyss uses dark gray by default.

Home Screen Logo Settings

Add a logo beside the menu button on Home. On other pages, the same logo replaces the upper-left Home icon while keeping its Home button function.

Media Bar Timing Settings

Choose how many seconds each item remains visible before the top media bar advances. Abyss uses 5 seconds by default.

Media Bar Image Type Settings

Choose the Jellyfin image type used behind items in the top media bar. If an item does not have that image, the media bar falls back to another available image.

Global Corner Rounding Settings

Choose how rounded corners appear throughout the Abyss theme. Lower values make cards, buttons, menus, and other interface elements more square; higher values make them more rounded. Abyss uses 24 pixels by default.

Font Override Settings

Optionally use a different web font with Abyss. Enter the font stylesheet URL supplied by Google Fonts or another font provider, then enter the exact font-family name. Leave both fields blank to keep the theme's normal font.

Lite Mode Settings

Turn Lite Mode on for lower-power mobile, TV, and embedded clients. It keeps Abyss colors, typography, spacing, and component styling while reducing blur, shadows, and entrance motion.

Existing Home Screen Sections

This area shows your current home screen sections. Sections made by/default by Jellyfin are labeled Jellyfin in blue, and sections made by this plugin are labeled in purple. You can change the three label colors below. Sections made by this plugin are editable and sections made by Jellyfin are not. Click 'Create Section' to create a new section. Click 'Edit Section' to edit sections made by this plugin. Drag sections to rearrange them. The first eligible section is labeled Media Bar and supplies the content for the top media bar while also remaining visible as a normal section below it. My Media and Latest Media cannot be used as the Media Bar.

New Section Type Settings

Select which type of section you want to create. After this, you can select how you want the content to be organized.
