HOME SCREEN MANAGER — CURRENT RELEASE GOALS
====================================================

Purpose
-------
Home Screen Manager is the third Jellyfin 10.11.11 plugin in the
Media Tagging Manager -> Collection Manager -> Home Screen Manager
workflow. It designs home sections that can display tagged media, collections,
libraries, or explicitly selected items while retaining Jellyfin's own rows.

Current scope
-------------
The plugin currently provides three Dashboard tabs:

1. Main Settings
2. Customization Settings
3. Create and Manage Home Screen Sections

Main Settings is intentionally empty.
Customization Settings applies supported Abyss variables through Jellyfin's
branding configuration. Create and Manage Home Screen Sections reads the
current user's official Jellyfin home-section display preferences, combines
them with saved plugin drafts, and saves their hybrid order. It also saves each plugin section's
type and selected manual, collection, tag, or library source.

This release does not inject or render plugin sections on the home screen. It
does not create collections, change media metadata, write NFO files, call
outside services, or start background work.

Implementation boundary
-----------------------
Before a feature is added, its exact Jellyfin 10.11.11 public extension point
must be verified in both the official Jellyfin source/documentation and the
local Jellyfin Plugin Base. A feature must not claim to change a Jellyfin home
screen unless the target-version API supports it and a real-server test records
the result.

Compatibility and packaging requirements
----------------------------------------
- Build against Jellyfin.Controller and Jellyfin.Model 10.11.11 using net9.0.
- Keep the Dashboard page as an embedded resource registered by IHasWebPages.
- Preserve the Home Screen Manager Noncommercial License 1.0.
- Every repository manifest entry requires a real release ZIP whose version,
  target ABI, framework, source URL, MD5 checksum, timestamp, and changelog all
  describe that exact ZIP.
