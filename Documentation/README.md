# Documentation Map

This folder keeps project documentation and planning records separate from the
plugin source code.

- `CHANGELOG.md` — chronological record of user-visible changes.
- `JELLYFIN_10.11.11_COMPATIBILITY_AUDIT.md` — source-level compatibility
  audit against Jellyfin 10.11.11.
- `project-goals.txt` — current product scope and acceptance boundaries.
- `goal-testing.txt` — real-server testing checklist and results log.

The public project guide is [README.md](../README.md).
